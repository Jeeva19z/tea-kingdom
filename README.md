# Tea Kingdom — Modern One Page Website

A responsive SPA-style landing page built with:
- HTML5
- CSS3
- Bootstrap 5.3
- Vanilla JavaScript
- Swiper.js
- Bootstrap Icons

## Run
Open `index.html` in a browser.

## Included
- Sticky transparent navbar
- Full-screen hero
- Animated reveal effects
- Story / brand section
- Swiper menu slider
- Gallery with Bootstrap lightbox
- Review slider
- Reservation / enquiry form with front-end validation
- Order online CTA
- Google Maps / phone links
- Mobile responsive layout

## Important
The images in `assets/` are crops/reference images from the image supplied for this project.
Before launching commercially, replace them with the original high-resolution Tea Kingdom photos and add the owner's approved menu, exact prices, social links and verified testimonials.

The form is front-end only. Connect it to Formspree, Jotform, a custom API, or your own backend before production.
